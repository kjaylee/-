The imported footer included `props.company_name`, and Save rejected `/sections/6/props/company_name cannot override the current brand identity`. The public component spec marks that property server-owned and never authorable. I deleted only the imported Footer and inserted the editor’s native Footer block. Save then succeeded and the footer derived identity from the current Brand Kit.
- **Suggested change:** The MJML importer should omit server-owned identity properties or normalize them into a native Footer. The error should also offer “Use current Brand Kit footer” directly, while preserving the modified content. This would remove an export/import round-trip trap without allowing identity overrides.
